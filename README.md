# Organization profile

This repository maintains UofT STAR's public GitHub welcome page.

## What to edit

- [`profile/README.md`](profile/README.md) appears on the organization overview. Keep it focused on joining the team, finding current projects, and taking the first steps.
- This root README explains how to maintain the profile; it is not the member onboarding guide.
- Detailed firmware setup, debugging, and testing instructions belong in [Avionics-Bay](https://github.com/UofT-STAR/Avionics-Bay).

## Before publishing a profile change

1. Preview the Markdown and check every link. A file present only in a local clone is not yet available to members on GitHub.
2. Link to detailed onboarding documents only after they exist on the destination repository's default branch. Until then, link to the repository itself.
3. Confirm team contacts and access instructions with the project lead. Keep retired projects and private repository links out of the public getting-started path.
4. Check that newcomers can complete the software steps without hardware and know whom to contact for their first bench session.
5. Submit the change for review. Editing this local clone alone does not update the live organization page.

The organization default is Read access, so organization membership alone does not grant permission to edit this repository. Contact Kai ([@KaiYT1](https://github.com/KaiYT1)) to arrange access or help with the GitHub contribution workflow.
